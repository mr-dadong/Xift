# Xift Application Icons

Cross-platform desktop and system tray icon assets for **Xift**.

## Files

| Path | Format | Target |
| :--- | :--- | :--- |
| `xift.svg` | Vector SVG (`1024x1024`) | Canonical source of truth |
| `xift.ico` | Multi-resolution ICO (`16/24/32/48/64/128/256`) | Windows executable & taskbar |
| `xift.icns` | Apple HIG ICNS (`16@1x` – `512@2x`, 10 chunks) | macOS `.app` bundle & Dock |
| `png/xift-{16..1024}.png` | Transparent PNG | Linux freedesktop (`hicolor`), docs, UI |
| `xift-tray-dark.svg` / `tray/xift-tray-dark-{16,32,64}.png` | Monochrome dark | Light taskbar / menu bar tray |
| `xift-tray-light.svg` / `tray/xift-tray-light-{16,32,64}.png` | Monochrome light | Dark taskbar / menu bar tray |
